1. Выходные данные

1.1. Форматы данных

1.1.1. Веб-интерфейс

  • HTML5 страницы с динамическим контентом;
  • JSON данные через REST API;
  • WebSocket сообщения в реальном времени;
  • Таблицы с сортировкой и фильтрацией;
  • Графические индикаторы статуса.

1.2. Отчёты и статистика

1.2.1. Сводные отчёты

  • Общее количество устройств;
  • Количество устройств онлайн/офлайн;
  • Статистика по типам устройств;
  • Статистика по вендорам;
  • Количество интерфейсов и каналов;
  • Количество активных алертов.

1.2.2. Детальная информация по устройству

  • Основные параметры (IP, тип, вендор);
  • Статус доступности (ping, SSH, SNMP);
  • Список интерфейсов с состоянием;
  • История выполненных команд;
  • История алертов;
  • Время последней проверки.

1.2.3. История команд

  • Дата и время выполнения;
  • Пользователь, выполнивший команду;
  • Тип команды;
  • Результат выполнения (успех/ошибка);
  • Вывод команды (полный текст).

1.2.4. Журнал алертов

  • Тип события (device_down, device_up, interface_down и т.д.);
  • Уровень важности (critical, warning, info);
  • Устройство и интерфейс;
  • Дата и время события;
  • Описание события.

1.3. REST API

  • Полный доступ ко всем данным через HTTP GET-запросы;
  • Поддержка пагинации, фильтрации и сортировки;
  • Аутентификация через JWT токены.

1.4. WebSocket

  • Real-time обновления статуса устройств;
  • Уведомления о новых алертах;
  • Результаты выполнения команд.
