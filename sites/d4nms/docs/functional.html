Функциональные характеристики программы

Программный продукт D4NMS предоставляет пользователю набор основных функциональных характеристик программы, который включает:

1. Мониторинг устройств:

  • Проверка доступности: Ping, SSH, SNMP;
  • Типы устройств: маршрутизаторы, коммутаторы, серверы, межсетевые экраны, точки доступа, IP-телефоны;
  • Мониторинг состояния портов и интерфейсов;
  • Отслеживание VLAN и IP-каналов связи;
  • Мониторинг протокола STP.

2. Управление устройствами

  • Выполнение CLI-команд через SSH;
  • Библиотека шаблонов команд для популярных вендоров;
  • История выполненных команд с временными метками;
  • Автоматическое выполнение команд по расписанию.

3. Система оповещений

  • Автоматические алерты при изменении статуса устройств;
  • Классификация по важности: критические предупреждения, информационные;
  • Журнал событий с фильтрацией и поиском.

4. Управление пользователями

5-уровневая ролевая модель:

  • Администратор — полный доступ;
  • VoIP Администратор — управление IP-телефонами;
  • Оператор — мониторинг и стандартные команды;
  • Пользователь — просмотр данных;
  • Гость — только журнал событий.

5. Производительность

  • До 1000 устройств на одном сервере;
  • Интервал проверки: настраиваемый (по умолчанию 60 сек);
  • До 50 одновременных пользователей.

6. Безопасность

  • Автоматическое шифрование SSH-паролей в базе данных (Fernet encryption);
  • Защита от SQL-инъекций через ORM;
  • CORS-политика для защиты API;
  • Аудит всех действий пользователей.

7. Интерфейс

  • Современный веб-интерфейс на React с Material-UI;
  • Обновления в реальном времени через WebSocket;
  • Адаптивный дизайн для работы на различных устройствах;
  • Интуитивная навигация и поиск;
  • Тёмная тема для комфортной работы.

8. Поддерживаемые вендоры

  • Cisco (IOS, IOS-XE);
  • Eltex (MES, ESR);
  • Huawei (VRP);
  • MikroTik (RouterOS);
  • Juniper (JunOS).
