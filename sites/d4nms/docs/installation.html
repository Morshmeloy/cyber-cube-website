1. Быстрый старт. Установка D4NMS

1.1. Общие сведения

  • Установка займёт 15–30 минут;
  • Потребуются права администратора;
  • Нужно подключение к интернету (для загрузки Docker);
  • После установки система будет доступна в браузере.

2. Установка на Windows

2.1. Требования к системе

  • Windows 10/11 (64-bit);
  • Права администратора;
  • Docker Desktop (будет установлен автоматически если отсутствует).

Минимальные требования:

  • OS: Windows 10 (64-bit) или новее;
  • RAM: 4 GB;
  • Disk: 10 GB свободного места;
  • CPU: 2 cores;
  • Hyper-V: Включён (для Docker).

Рекомендуемые требования:

  • RAM: 8 GB+;
  • Disk: 20 GB+;
  • CPU: 4 cores+;
  • SSD: для лучшей производительности.

2.2. Шаг 1. Предварительные действия

Найдите папку с инсталлятором:

  1. Откройте проводник Windows (значок папки на панели задач);
  2. Перейдите в папку проекта Project_D4NMS;
  3. Откройте папку installer;
  4. Откройте папку windows.

Найдите файлы:

  • install.bat;
  • install-D4NMS.ps1;
  • Инструкция для пользователей Windows.md.

2.3. Шаг 2. Запуск установки

Перед установкой сохраните работу и закройте все программы.
  1. Двойной клик левой кнопкой мыши по файлу install.bat;
  2. Появится окно с вопросом «Разрешить этому приложению вносить изменения?» — нажмите «Да»;
  3. Откроется чёрное окно (терминал) с процессом установки.

2.4. Шаг 3. Инструкции на экране

Инсталлятор будет задавать вопросы:

Вопрос 1: "Выберите режим установки [1-2]:"

  1. Development — для тестирования (рекомендуется для первого раза);
  2. Production — для постоянной работы.

Введите 1 и нажмите Enter.

Вопрос 2: "Директория установки [C:\Program Files\D4NMS]:"
Куда установить программу? Нажмите Enter (программа установится в стандартное место).

Вопрос 3: "Порт для Backend API [8000]:"
На каком порту будет работать сервер? Нажмите Enter (остаётся 8000).

Вопрос 4: "Порт для Frontend [3000]:"
На каком порту будет веб-интерфейс? Нажмите Enter (остаётся 3000).

Вопрос 5: "Интервал проверки устройств (секунды) [60]:"
Как часто проверять устройства? Нажмите Enter (каждые 60 секунд).

2.5. Шаг 4: Завершение установки

Дождитесь завершения установки. При этом инсталлятор автоматически:

  1. Проверит наличие Docker (установит если нужно);
  2. Создаст все необходимые файлы;
  3. Запустит систему;
  4. Создаст ярлык на рабочем столе.

2.6. Шаг 5: Готово. Откройте систему

После завершения:

  1. На рабочем столе появится ярлык «D4NMS»;
  2. Двойной клик по ярлыку — откроется браузер;
  3. Или откройте браузер вручную и введите: http://localhost:3000
Логин: admin / Пароль: admin123
После первого входа обязательно смените пароль!

3. Установка на Linux

3.1. Требования к системе

  • Linux (Ubuntu 20.04+, Debian 11+, CentOS 8+, или другие современные дистрибутивы);
  • Права sudo;
  • Docker и Docker Compose (будут установлены автоматически если отсутствуют).

Минимальные требования:

  • OS: Ubuntu 20.04+, Debian 11+, CentOS 8+, или аналоги;
  • RAM: 2 GB;
  • Disk: 10 GB свободного места;
  • CPU: 2 cores.

Рекомендуемые требования:

  • RAM: 4 GB+;
  • Disk: 20 GB+;
  • CPU: 4 cores+;
  • SSD: для лучшей производительности.

3.2. Шаг 1. Предварительные действия

Найдите папку с инсталлятором через файловый менеджер (Nautilus, Dolphin, Thunar и т.д.):

  1. Откройте файловый менеджер;
  2. Перейдите в папку проекта D4NMS;
  3. Откройте папку installer;
  4. Откройте папку linux.

Найдите файлы:

  • install-gui.sh;
  • Инструкция для пользователей Linux.md.

3.3. Шаг 2. Запуск установки

Способ 1:

  1. Двойной клик левой кнопкой мыши по файлу install-gui.sh;
  2. Появится вопрос «Выполнить?» или «Run?» — выберите «Выполнить» или «Run»;
  3. Откроется терминал с процессом установки.

Способ 2 — через терминал (если двойной клик не работает):

  1. Откройте терминал (Ctrl+Alt+T);
  2. Введите команды:
cd /путь/к/проекту/installer/linux chmod +x install-gui.sh ./install-gui.sh

3.4. Шаг 3: Ввод пароля администратора

Терминал попросит ввести пароль:

[sudo] password for username:

Введите пароль вашего пользователя (при вводе символы не отображаются).

3.5. Шаг 4. Инструкции на экране

Инсталлятор будет задавать вопросы:

Вопрос 1: "Выберите режим [1-2]:"

  1. Development — для тестирования;
  2. Production — для постоянной работы.

Введите 1 и нажмите Enter.

Вопрос 2: "Директория установки [/opt/d4nms]:"
Просто нажмите Enter (установится в /opt/d4nms), или введите свой путь.

Вопрос 3: "Порт для Backend API [8000]:"
Нажмите Enter (остаётся 8000).

Вопрос 4: "Порт для Frontend [3000]:"
Нажмите Enter (остаётся 3000).

Вопрос 5: "Интервал проверки устройств (секунды) [60]:"
Нажмите Enter (каждые 60 секунд).

  2. Создаст все необходимые файлы;
  3. Запустит систему;
