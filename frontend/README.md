# Д4 Технологии — 3D-куб навигации

Интерактивный сайт-визитка на чистом TypeScript + Vite, без фреймворка. Точки входа и разделы ещё не наполнены реальным контентом (везде плейсхолдеры) — сейчас это готовый интерактивный каркас.

## Стек

- TypeScript + Vite, `type="module"`, без рантайм-зависимостей
- Никакого React/Vue — DOM-модули в стиле фабричных функций с замыканиями (`createCube`, `createSubmenu`, `createPlasma`, `createAudioEngine`)
- Бэкенда нет — чистая статика (`vite build` → `dist/`)

## Как всё запускается

`index.html` — статичная разметка (слои фона, контейнеры дождя, заголовок, canvas лого, `.scene/.cube`, плазменный экран, контейнер подменю, кнопка «назад») → `src/main.ts` собирает нужные DOM-узлы в `SiteElements` (`types/site-elements.ts`) и вызывает `initSiteNavigation(elements)` из `navigation/navigation.ts`.

## `navigation/navigation.ts` — оркестратор

Сам ничего не рендерит, только связывает остальные модули колбэками:

1. `createAudioEngine()` — заводит звук
2. `applyFaceColorCssVariables()` — прокидывает `faceColors` (`settings/navigation/faces.ts`) в CSS-переменные `--face-color-*`, которые читает `cube.css` (единственный источник цвета граней)
3. `startBackgroundSlideshow()`, `createRainEffect()`, `applyLumaKeyCutout()` на лого шапки — фон
4. `createCube()` → клик по грани открывает `submenu.show(face)`; клик по свёрнутому кубу закрывает плазму; активация грани блокируется, пока открыты подменю/плазма
5. `createSubmenu()` → `onMiniCubeActivated` открывает `plasma.show(цвет, buildPlaceholderContent(...))`; разворачивание/сворачивание подменю ставит куб на паузу/возобновляет автовращение
6. `createPlasma()` → колбэки дают плазме управлять состоянием куба и подменю (спрятать кубы подменю, приостановить вращение и т.д.)
7. кнопка «назад»: если плазма активна — закрыть её, иначе закрыть подменю

## Навигационные модули (`src/navigation/`)

- **`cube.ts`** — главный куб. Строит 6 граней из `settings/navigation/faces.ts::cubeFaceDefinitions` (иконки/лейблы/aria), вешает лого через `logo-luma-key.ts`. Перетаскивание мышью/тачем с инерцией и привязкой к ближайшей грани на 90°, автовращение в простое — константы в `settings/navigation/cube.ts`. По клику определяет активную грань (`resolveFaceFromRotation`).
- **`submenu.ts`** — 27 мини-кубов (сетка 3×3×3, `buildMiniCubeSlots`), грани красятся тем же `faceColors`. `show()` — «взрыв» главного куба и разлёт мини-кубов с задержкой по расстоянию от центра; `hide()` — гравитационный коллапс обратно. `hideCubesOnly/restoreCubesOnly` — когда поверх открытого подменю открывается плазма. Константы — `settings/navigation/submenu.ts`.
- **`plasma.ts`** — ЭЛТ-экран. `show(color, content)` сворачивает куб в угол экрана и печатает текст по символам (`TYPEWRITER_CHAR_DELAY_MS`); `hide()` разворачивает обратно, восстанавливает заголовок либо кубы подменю.

## Звук (`src/audio/audio-engine.ts`)

Web Audio API: постоянный синтезированный гул трансформатора (гармоники-осцилляторы), периодические сэмплы `fon.mp3`, звук вращения `kub4.mp3` (зациклен на время драга), «бум» привязки к грани (синтез), звуки `open.mp3`/`close.mp3` для плазмы, тихий моторный гул на автовращении. Пути к сэмплам и часть параметров огибающей — в `settings/audio/audio.ts`. Всё звучит только после первого клика/тача (`unlockOnFirstGesture`) — требование браузеров к Web Audio API.

## Фон (`src/background/`)

- **`background-slideshow.ts`** — кросс-фейд между двумя слоями раз в `SLIDESHOW_INTERVAL_MS` по списку `BACKGROUND_PHOTOS` (обе константы — `settings/background/slideshow.ts`)
- **`rain.ts`** — спавнит `RAINDROP_COUNT` + `PURPLE_TRAIL_COUNT` div-ов дождя со случайными параметрами, дальше всё на CSS-анимациях
- **`logo-luma-key.ts`** — рисует картинку на canvas и прозрачно вырезает тёмный фон по яркости пикселя; используется и для лого в шапке, и для лого на лицевой грани куба (общая функция — задача идентична в обоих местах)

## `src/settings/` — контент и настройки сайта

Единая точка правды для того, что «заполняется на сайте», и всех именованных констант:

- `site/site.ts` — имя сайта, путь к лого
- `navigation/faces.ts` — лейблы граней + цвета (`faceColors`)
- `navigation/{cube,submenu,plasma}.ts` — тайминги и физика каждого узла навигации
- `background/{slideshow,rain,luma-key}.ts` — константы фоновых эффектов
- `audio/audio.ts` — пути к сэмплам + именованные параметры огибающей

Модули-реализации импортируют константы отсюда вместо локальных `const`.

## `src/types/` — только общие контракты

Интерфейсы, которые пересекают границы модулей и позволяют `navigation.ts` соединять куб/подменю/плазму колбэками, не давая им импортировать друг друга напрямую: `site-elements.ts`, `audio.ts`, `cube.ts`, `submenu.ts`, `plasma.ts`, `navigation.ts` (типы граней). Локальные, однофайловые типы (`Rotation`, `MiniCubeSlot` и т.п.) остаются в файлах реализации.

## `src/styles/`

CSS 1:1 повторяет деление `src/`: `base/` (сброс + общие стили), `background/` (фон + дождь + заголовок), `navigation/` (куб + подменю + плазма). Порядок `@import` в `styles/index.css` — это z-order визуальных слоёв страницы, менять его нельзя.

## Известные ограничения

- Контент разделов — плейсхолдер (`buildPlaceholderContent` в `settings/navigation/plasma.ts`), реальных текстов ещё нет
- `.env`-инфраструктуры нет: бэкенда нет, поэтому и хранить там пока нечего. При появлении бэкенда/формы обратной связи секреты должны жить на сервере, а не во фронтенде — сюда попадут только публично безопасные значения (см. `settings/`)
