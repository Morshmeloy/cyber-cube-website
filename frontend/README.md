# Д4 Технологии — 3D-куб навигации

Интерактивный сайт-визитка на чистом TypeScript + Vite, без фреймворка. Куб с 6 гранями открывает полноразмерные страницы с реальным контентом компании; есть общий футер и отдельная страница «Правовая информация», не привязанная к граням куба.

## Стек

- TypeScript + Vite, `type="module"`, без рантайм-зависимостей
- Никакого React/Vue — DOM-модули в стиле фабричных функций с замыканиями (`createCube`, `createPlasma`, `createSiteFooter`, `createImageCarousel`, `createAudioEngine`)
- Бэкенда нет — чистая статика

## Разработка

Требуется Node.js (см. `devDependencies` в `package.json`; Vite 8 и TypeScript ~6.0).

```bash
cd frontend
npm install        # установка зависимостей
npm run dev        # dev-сервер с HMR — http://localhost:5173
npm run build      # tsc (проверка типов) + vite build → результат в frontend/dist/
npm run preview    # локально поднять собранный frontend/dist/ и проверить прод-сборку
```

`dist/` — статические файлы (`index.html`, `assets/*.js`, `assets/*.css`), готовые к раздаче любым статическим хостингом; на бэкенд не завязаны.

## Как всё запускается

`index.html` — статичная разметка (слои фона, дождь, заголовок/лого, `.scene/.cube`, плазменный экран, футер) → `src/main.ts` собирает нужные DOM-узлы в `SiteElements` (`types/site-elements.ts`) и вызывает `initSiteNavigation(elements)` из `navigation/navigation.ts`.

## `navigation/navigation.ts` — оркестратор

Сам ничего не рендерит, только связывает остальные модули колбэками:

1. `createAudioEngine()` — заводит звук
2. `applyFaceColorCssVariables()` — прокидывает `faceColors` (`settings/navigation/faces.ts`) в CSS-переменные `--face-color-*`, которые читает `cube.css`
3. `startBackgroundSlideshow()`, `createRainEffect()`, `applyLumaKeyCutout()` на лого шапки — фон
4. `createCube()` → клик по грани сразу открывает `plasma.show(цвет_грани, pageContentByFace[грань])` — без промежуточных шагов
5. `createPlasma()` → `show()` если панель уже открыта, просто переключает контент (кросс-фейд, без анимации куба); `hide()` всегда возвращает к кубу
6. `createSiteFooter()` → те же `onNavigate(face)`, что и у куба, плюс `onOpenLegal()` — открывает страницу «Правовая информация» (не привязана к грани)

## Навигационные модули (`src/navigation/`)

- **`cube.ts`** — главный куб. Строит 6 граней из `settings/navigation/faces.ts::cubeFaceDefinitions`, лого через `logo-luma-key.ts`. Перетаскивание мышью/тачем с инерцией и привязкой к ближайшей грани на 90°, автовращение в простое — константы в `settings/navigation/cube.ts`. По клику определяет активную грань (`resolveFaceFromRotation`) и полностью скрывается (`display:none`), пока открыта страница.
- **`plasma.ts`** — панель страницы. `show(color, content)` — вспышка/сжатие куба, затем плавное появление панели (fade + scale + blur-in) и постепенное проявление блоков контента; `hide()` — закрытие и возврат куба; повторный `show()` при уже открытой панели — кросс-фейд контента без анимации куба. Рендерит `PageContent`/`PageBlock[]` (`types/page-content.ts`): заголовки, абзацы, списки, карточки, галерея-карусель, контактные блоки.
- **`certificate-carousel.ts`** — зацикленная 3D-«coverflow» карусель для блока `imageGallery`: активный слайд по центру и ровно (наклон соседних плавно пропорционален расстоянию), перетаскивание/колесо/стрелки, клик по центральному слайду открывает лайтбокс с навигацией стрелками/клавиатурой и увеличением без обрезки (`object-fit: contain`).
- **`footer.ts`** — общий футер (лого, навигация по граням с подсветкой в цвет грани при наведении, контакты, реквизиты). Виден и на кубе, и поверх любой открытой страницы, ниже по прокрутке.

## Грани куба и страницы (`src/settings/navigation/pages/`)

`pageContentByFace` (`pages/index.ts`) сопоставляет каждую из 6 граней с контентом:

| Грань | Контент |
|---|---|
| front | `auth.ts` — «Авторизация» (заглушка: личного кабинета/бэкенда нет) |
| back | `about.ts` — «О нас» (сертификаты/партнёрства, карусель) |
| right | `services.ts` — «Решения и услуги» |
| left | `software.ts` — «Программное обеспечение» (D4NMS) |
| top | `support.ts` — «Поддержка» |
| bottom | `contacts.ts` — «Контакты» |

`legal.ts` — «Правовая информация» — вне этой таблицы, без грани; открывается только по ссылке в футере.

## Звук (`src/audio/audio-engine.ts`)

Web Audio API: постоянный синтезированный гул трансформатора, периодические сэмплы `fon.mp3`, звук вращения `kub4.mp3` (зациклен на время драга), «бум» привязки к грани (синтез), звуки `open.mp3`/`close.mp3` для панели, тихий моторный гул на автовращении. Пути к сэмплам и параметры огибающей — в `settings/audio/audio.ts`. Звучит только после первого клика/тача (`unlockOnFirstGesture`) — требование браузеров к Web Audio API.

## Фон (`src/background/`)

- **`background-slideshow.ts`** — кросс-фейд между двумя слоями раз в `SLIDESHOW_INTERVAL_MS` по списку `BACKGROUND_PHOTOS`
- **`rain.ts`** — спавнит `RAINDROP_COUNT` + `PURPLE_TRAIL_COUNT` div-ов дождя, дальше CSS-анимации
- **`logo-luma-key.ts`** — рисует картинку на canvas и прозрачно вырезает тёмный фон по яркости пикселя; используется для лого в шапке и на лицевой грани куба

## `src/settings/` — контент и настройки сайта

Единая точка правды для всего, что «заполняется на сайте», и именованных констант:

- `site/site.ts` — имя сайта, пути к лого (обычное + чистый векторный вариант для футера)
- `site/footer.ts` — пункты навигации футера, контакты, реквизиты
- `navigation/faces.ts` — лейблы и иконки граней + цвета (`faceColors`)
- `navigation/pages/*.ts` — контент страниц (см. таблицу выше)
- `navigation/{cube,plasma,carousel}.ts` — тайминги и физика куба, панели, карусели
- `background/{slideshow,rain,luma-key}.ts` — константы фоновых эффектов
- `audio/audio.ts` — пути к сэмплам + параметры огибающей

Модули-реализации импортируют константы отсюда вместо локальных `const`.

## `src/types/` — только общие контракты

Интерфейсы, пересекающие границы модулей: `site-elements.ts`, `audio.ts`, `cube.ts`, `plasma.ts`, `page-content.ts` (`PageBlock`/`PageContent`), `navigation.ts` (`FaceName`, `CubeFaceDefinition`, `FooterNavItem`). Локальные, однофайловые типы остаются в файлах реализации.

## `src/styles/`

CSS 1:1 повторяет деление `src/`: `base/` (сброс + общие стили), `background/` (фон + дождь + заголовок/лого), `navigation/` (куб + панель страницы + карусель/лайтбокс), `site/footer.css`. Порядок `@import` в `styles/index.css` — это z-order визуальных слоёв страницы, менять его нельзя.

## Известные ограничения

- «Авторизация» (лицевая грань) — информационная заглушка: реального личного кабинета/бэкенда нет
- `.env`-инфраструктуры нет: бэкенда нет, поэтому и хранить там пока нечего. При появлении бэкенда/формы обратной связи секреты должны жить на сервере, а не во фронтенде
